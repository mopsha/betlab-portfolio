nflverse download). CI (`.github/workflows/ci.yml`) runs the same suite on
Python 3.13 for every push to `main` and every pull request.

## Conventions

- Tests must not touch real ledger or config files. Use `tmp_path` and `monkeypatch`
  (see `test_ledger_never_duplicates_or_reprices`).
- No test may need an API key. Network use is limited to free public data (nflverse).
- New logic gets a test in the matching file, or a new `test_<module>.py`.
- Football grading tests also retain closing push probability for personal CLV;
  publication tests verify it reaches Postgres as a grading field.
